Question 6 · Quick reference

Responsive CSS
cheat sheet

Filters

Modify the visual treatment of an element.

filter: grayscale(1);

Media Queries

Apply a new rule when the viewport matches a condition.

@media (max-width: 700px) { }

Responsive Design

Let content adapt to its container, not a single device.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Typography

Scale type smoothly with a minimum, ideal, and maximum.

font-size: clamp(1rem, 2vw, 1.5rem);
